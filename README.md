# تطبيق المحل (جاهز للتثبيت)

المجلد كله موقع ثابت (لا يحتاج خادماً). index.html هو التطبيق.

## نشره (أسهل طريقة، من حاسوب)
1. افتح app.netlify.com/drop
2. اسحب هذا المجلد كاملاً إلى الصفحة.
3. سجّل حساباً مجانياً لتثبّت الموقع (وإلا يُحذف خلال ساعة).
4. ستحصل على رابط https يفتح التطبيق.

## تثبيته
- أندرويد (Chrome): القائمة ثم تثبيت التطبيق.
- آيفون (Safari): مشاركة ثم إضافة إلى الشاشة الرئيسية.
- الحاسوب (Chrome أو Edge): أيقونة التثبيت في شريط العنوان.
